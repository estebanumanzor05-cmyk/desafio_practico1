# Sivar Tours

Página web de Sivar Tours, un emprendimiento de tours de un día por los 14 departamentos de El Salvador.
Desafío Práctico I - Desarrollo Web I, ESEN 2026.

Hecho con HTML5 y CSS3.

## Páginas

- `index.html`: inicio, buscador por departamento y los 5 tours más famosos
- `viajes.html`: todos los tours ordenados por departamento
- `quienes-somos.html`: propósito, misión y visión
- `contacto.html`: datos de contacto y formulario
- `reservar.html`: formulario para reservar un tour
- `gracias.html`: mensaje después de enviar un formulario

## Carpetas

- `css/estilos.css`: todos los estilos
- `img/`: ícono de la lupa
